# An Attempt to Code a Candle

A small experiment in organic coding (spamdigital.com/project/an-attempt-to-code-a-candle).

Trying to understand what happens when code behaves less like architecture and more like weather, wax, ritual, entropy and time.

This project is unfinished on purpose.
I keep adding to it slowly.
